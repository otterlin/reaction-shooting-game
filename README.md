# 🎯 神槍手反射實驗室 — 射擊反應時間測定遊戲

一個以**射擊靶場**為主題的網頁反應時間測定遊戲，專為測量人類視覺反應時間（從標靶出現到點選射擊的毫秒數）並進行 **5 次測量平均統計** 而設計。

## ✨ 功能特色

- **🎯 隨機靶位與隨機延遲**：每發標靶會在 `1.2 秒 ～ 3.4 秒` 之間於隨機座標彈出，防止預判搶快。
- **⏱️ 高精度毫秒計時**：結合 `requestAnimationFrame` 與 `performance.now()`，精確計算標靶實際渲染到點擊命中的時間差（單位：`ms`）。
- **🚫 搶快防呆機制**：若在標靶出現前提前點擊開槍，系統會發出犯規警示並重新計時該發，確保 5 次數據皆為有效反應。
- **📊 五次平均與統計圖表**：
  - 即時顯示第 1～5 發各別反應時間與即時平均值
  - 完成 5 次射擊後自動產生**五次平均反應時間**、**最快/最慢紀錄**、**穩定度標準差 (SD)**、**命中環數**與**長條圖分佈**
  - 支援一鍵複製五次實驗數據，方便課堂統計或個人紀錄
- **🔊 合成射擊音效**：內建 Web Audio API 即時合成槍聲、標靶彈出聲與完成音效（無須外部音檔，支援靜音切換）。

## 🚀 部署至 GitHub Pages

1. 將本資料夾內容推送至 GitHub 儲存庫（Repository）。
2. 進入 GitHub 儲存庫的 **Settings** → **Pages**。
3. 在 **Build and deployment** 下選擇 **Deploy from a branch**，分支選擇 `main`（目錄選擇 `/ (root)`），點擊 **Save** 即可透過網址遊玩。
